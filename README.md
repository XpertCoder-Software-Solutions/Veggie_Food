# Veggie Food Website (React + Vite)

## التشغيل على الجهاز
```bash
npm install
npm run dev      # يفتح الموقع على http://localhost:5173
```

## تجهيز النسخة للرفع
```bash
npm run build    # الناتج في فولدر dist
```
ارفع محتوى فولدر `dist` على أي استضافة (Hostinger / cPanel / Netlify / Vercel).

## تعديل المنيو والأسعار
كل الأصناف والأسعار في `src/data.js` (متغير `CATEGORIES`)، ورقم الواتساب في `WHATSAPP`.

## تبديل الصور
الصور في `public/img` بنفس الأسماء:
vegpizza (بيتزا) · shrimp (باستا) · batter (كريب حادق) · crepe (كريب حلو) · risotto (رايز وريزوتو) · fries (سايد) · sauce (إضافات) · cheese (صورة الهيرو) · oven (جزء حكايتنا)
